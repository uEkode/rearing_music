# 牧音管家安卓演示版 0.1.0

基于团队提供的《牧音管家页面交互.html》继续开发，沿用原页面和主要交互。本版本为离线交互演示：不连接真实 AI、后端和设备，不采集声音，不实际播放音频，不发送系统通知。

## 本次更新

- 演示页按职责拆成 HTML 外壳、4 层样式和 15 个脚本模块，`file://` 下可直接运行。
- 演示数据集中到 `fixtures.js`，视图只经 `datasource.js` 取数；应激等级改由 `stress.js` 按分贝阈值推导。
- 圈舍只存分贝、在线、授权、干预状态这些客观量，不再把「高度应激」直接写进数据；平均分贝、授权圈舍数等改为实时计算。
- 首页新增圈舍状态分类（全部 / 干预中 / 应激 / 正常 / 离线），不再折叠；圈舍卡改为只读，安抚与复测统一进圈舍详情弹层。
- 「处理中」并入待处理，筛选为 全部 / 待处理 / 已处理，铃铛角标与列表条数一致。
- 圈舍管理里的开关改为真实授权，关闭后该圈舍从首页移除并随存档保留；免打扰时段改为直接选开始/结束时间，弹层「完成」固定在底部。
- 可点元素改为原生按钮并支持键盘操作，弹层支持 Esc 关闭、关闭后焦点回到原入口，小控件点击区域补到 44px。
- 修正暂停播放后圈舍仍显示「干预中」、同一事件重复处理等问题
- 本地存档升级到 v2，旧版进度会重置一次。

## 安装与演示

1. 将 APK 发到安卓手机，允许用于打开该文件的应用安装未知来源应用，按手机提示安装。
2. 最低支持 Android 8.0；需要手机具备正常可用的 Android System WebView。
3. 打开「牧音管家·演示」，阅读说明。
4. 首页按「圈舍状态」筛选查看，点 B 区圈舍卡进详情，点「快捷安抚」带入干预页，再点播放。本版仅模拟播放状态。
5. 切到事件页，处理一条待处理事件，回首页看圈舍状态与角标变化。
6. 在「我的 → 圈舍管理」关闭一间授权，确认首页少一张卡；在消息推送设置里改免打扰时段。
7. 关闭后重开检查记录；需要重演时点击顶部「重置演示」并确认。

卸载或清除应用数据会丢失本机演示记录。演示版本无需注册或登录，不申请网络、麦克风和存储权限。

## 验证范围

已通过 APK 签名验证、应用包信息检查，以及桌面 Chromium 的手机尺寸交互测试。测试包括重构前后 DOM 快照、关键元素位置与尺寸比对基本一致，圈舍分类、授权持久化、免打扰设置、复测与重置流程均按预期。

尚未完成真实安卓设备的安装、WebView 运行、系统返回键与系统安全区域验证。请先由队友安装试用，反馈手机型号、安卓版本、出问题的操作和截图。

## 开发文件

- `assets/index.html`：页面外壳，只保留挂载点和样式、脚本引用。
- `assets/css/`：设计令牌、基础样式、组件样式、WebView 适配四层。
- `assets/js/`：交互分发、路由渲染、取数接口、演示数据、启动入口、播放器、弹层、滑块、状态与存档、应激判定、界面工具。
- `assets/js/views/`：首页、干预、事件、我的四个页面视图。
- `src/cn/muyin/demo/MainActivity.java`：安卓 WebView 外壳、返回处理和重置确认。
- `AndroidManifest.xml`：应用名、最低版本和权限等配置。
- `res/`：图标和系统主题。
- `build.ps1`：可重复构建脚本，无需 Gradle 或额外第三方运行库。

## 构建

准备 JDK（本次使用 26）和 Android SDK：`platforms;android-35`、`build-tools;35.0.0`。PowerShell 执行：

```powershell
./build.ps1 -SdkRoot '你的Android SDK目录' -JdkHome '你的JDK目录'
```

脚本会在 `.local/` 创建本机演示签名密钥和构建文件，并输出 APK。密钥使用公开的测试密码 `android`，仅用于演示，不用于商店发布。源码压缩包不包含密钥；不同电脑新建密钥签出的安装包不能直接覆盖此前签名的版本。后续需要同签名更新时，请保留当前项目的 `.local/demo-signing.jks`，不要提交到公开仓库。

## 后续真实功能接入

真实 AI、后端、设备控制、音频播放和推送需要另行实现、联调并验证。接入时主要改 `assets/js/datasource.js`（把取数换成后端接口）和 `stress.js` 的 `evaluate()`；现有后端接口只覆盖登录、账号、养殖场和圈舍。当前界面上的分贝、风险等级、效益金额和自动干预次数均不是实测成果。
