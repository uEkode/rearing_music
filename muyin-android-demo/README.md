# 牧音管家安卓演示版 0.1.0

基于团队提供的《牧音管家页面交互.html》继续开发，沿用原页面和主要交互。本版本为离线交互演示：不连接真实 AI、后端和设备，不采集声音，不实际播放音频，不发送系统通知。

## 本次新增与修正

- 将固定尺寸手机外框改成适应实际屏幕的布局，移除模拟手机状态栏。
- 提供安卓启动图标、系统安全区域处理和返回行为。
- 全程显示演示数据标识，避免把模拟操作当作真实监测。
- 告警处理、干预计数和提醒设置保存在本机；退出后正在执行的模拟干预转为等待确认。
- 提供需要确认的“重置演示”，便于多次排练。
- 首页、事件列表和设备列表使用一致的数量和设备状态。
- 修正处理告警后模拟播放仍继续的问题，以及再次打开时弹窗遮挡的问题。
- 将报告导出、设备重连、试听等未实现能力改成准确的演示提示。

## 安装与演示

1. 将 APK 发到安卓手机，允许用于打开该文件的应用安装未知来源应用，按手机提示安装。
2. 最低支持 Android 8.0；需要手机具备正常可用的 Android System WebView。
3. 打开“牧音管家·演示”，阅读说明。
4. 首页选择 B 区，点击“快捷安抚”，进入干预页点击播放。本版仅模拟播放状态。
5. 切到事件页，确认记录变化，点击处理，再查看首页圈舍状态。
6. 关闭后重开检查记录；需要重演时点击顶部“重置演示”并确认。

卸载或清除应用数据会丢失本机演示记录。演示版本无需注册或登录，不申请网络、麦克风和存储权限。

## 验证范围

已通过 APK 签名验证、应用包信息检查，以及桌面 Chromium 的手机尺寸交互测试。测试包括模拟干预、计数、告警处理、本地保存、重置确认、返回逻辑和 360/390/412/768px 布局。

尚未完成真实安卓设备的安装、WebView 运行、系统返回键与系统安全区域验证。请先由队友安装试用，反馈手机型号、安卓版本、出问题的操作和截图。

## 开发文件

- `assets/index.html`：团队原型基础上的演示页面。
- `src/cn/muyin/demo/MainActivity.java`：安卓 WebView 外壳、返回处理和重置确认。
- `AndroidManifest.xml`：应用名、最低版本和权限等配置。
- `res/`：图标和系统主题。
- `build.ps1`：可重复构建脚本，无需 Gradle 或额外第三方运行库。

## 构建

准备 JDK（本次使用 26）和 Android SDK：`platforms;android-35`、`build-tools;35.0.0`。PowerShell 执行：

```powershell
./build.ps1 -SdkRoot '你的Android SDK目录' -JdkHome '你的JDK目录'
```

脚本会在 `.local/` 创建本机演示签名密钥和构建文件，并输出 APK。密钥使用公开的测试密码 `android`，仅用于演示，不用于商店发布。源码压缩包不包含密钥；不同电脑新建密钥签出的安装包不能直接覆盖此前签名的版本。后续需要同签名更新时，请保留当前项目的 `.local/demo-signing.jks`，不要提交到公开仓库。
